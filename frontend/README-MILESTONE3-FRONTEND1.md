# Milestone 3 - Frontend 1

This version includes:
- Tailwind CSS v4 setup with Vite
- Recharts for expiry/inventory analytics charts
- Shared JWT-aware API handling for protected frontend requests
- Login/Register routed to the dedicated authentication pages
- Existing expiry dashboard, filters, table, summary cards and analytics preserved

## Setup

```powershell
npm install
npm run dev
```

Backend should be running on `http://localhost:8082`.
Frontend runs on `http://localhost:3000`.


## Styling update
- Frontend styling is implemented with Tailwind CSS v4.
- Recharts is used for analytics charts.
- Supplier Management UI includes dashboard cards, search/filter, supplier table, add/edit/delete/view flows.
